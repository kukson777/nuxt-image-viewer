**Nuxt Image Viewer** is a lightbox module for Nuxt 3 and 4. An image expands from its place on the page, the viewer scrolls through the images of its group in an endless strip, zooms in every way people expect, and closes with a drag — the image flies back to where it came from.

## Why another lightbox

It started inside a production app that needed a lightbox made for Nuxt: no global CSS to fight, no imperative setup per page, and no DOM work for the person writing the page. Every duration, curve, spring and gesture threshold is tuned to feel like a native photo app, and the whole viewer is one small Vue component.

- **Mark, don't wire.** Add `<ZoomImage>` or a `data-image-viewer` attribute — no click handlers, no refs, no `onMounted`.
- **No blank frames.** All slides are in the DOM and show the copy already loaded on the page while the full image loads.
- **No dependencies.** Plain Vue, plain CSS and inline SVG icons. The viewer itself is loaded on the first open.
- **Customisable at every level.** Module options, per-call options, CSS variables, BEM classes, or your own styles from scratch.
