The module is built to be easy to use from an AI coding agent: every public type has JSDoc, the API is small and predictable, and this site serves its content in machine-readable form.

## MCP server

The documentation is also an MCP server at `/mcp` (streamable HTTP) with `list-pages` and `get-page` tools. Add it to your agent:

```json [.mcp.json]
{
  "mcpServers": {
    "nuxt-image-viewer": {
      "type": "http",
      "url": "https://<this site>/mcp"
    }
  }
}
```

## A prompt that works

```md
Add nuxt-image-viewer to this Nuxt app (docs: <this site>/llms-full.txt).
Use <ZoomImage> for the images in <file>, group them with data-image-viewer-group,
pass the natural width and height of each full image, and match the viewer colours
to our theme with the --image-viewer-* CSS variables.
```

## The cheat sheet

- **Mark images:** `<ZoomImage src width height caption?>` — width/height of the **full** image. Group with `data-image-viewer-group` on a container.
- **Options for one gallery:** wrap it in `<ImageViewerGroup :options="{ ... }">` — anything `open()` takes, buttons and arrows included.
- **Plain images:** `img[data-image-viewer]` plus optional `data-image-viewer-src|width|height|caption`.
- **From code:** `useImageViewer().open(items, index?, options?)` — auto-imported, client-only, items need only `src`.
- **Configure:** `nuxt.config` → `imageViewer` (`ModuleOptions`); per call with `ImageViewerOpenOptions`.
- **Style:** `--image-viewer-*` variables; `.image-viewer__*` BEM classes (unlayered CSS wins); `css: false` to start from scratch.
- **Types:** `import type { ImageViewerItem, ImageViewerOpenOptions, ImageViewerApi } from 'nuxt-image-viewer'`.
