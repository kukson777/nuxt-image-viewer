## Hide a chat widget while the viewer is open

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  imageViewer: {
    hide: ['jdiv', '#intercom-container', '#crisp-chatbox'],
  },
})
```

## One image, no gallery

Each `<ZoomImage>` in its own group:

```vue
<template>
  <figure data-image-viewer-group>
    <ZoomImage v-bind="photo" />
  </figure>
</template>
```

Or from code: `useImageViewer().open({ src: '/photos/poster.jpg' })`.

## A gallery from an API

```vue
<script setup lang="ts">
const { data: photos } = await useFetch('/api/photos')
const viewer = useImageViewer()
</script>

<template>
  <button type="button" @click="viewer.open(photos ?? [])">
    View all {{ photos?.length }} photos
  </button>
</template>
```

## Deep link to a photo

```vue
<script setup lang="ts">
const route = useRoute()
const router = useRouter()
const viewer = useImageViewer()

onMounted(() => {
  const index = Number(route.query.photo)
  if (Number.isInteger(index))
    viewer.open(photos, index)
})

watch([viewer.isOpen, viewer.index], ([open, index]) => {
  router.replace({ query: open ? { photo: index } : {} })
})
</script>
```

## A product gallery without the page dimming

```ts
viewer.open(productPhotos, 0, {
  bgOpacity: 1,
  closeOnVerticalDrag: false,
  ui: { counter: false, fullscreen: false },
})
```

```css
:root {
  --image-viewer-bg: #fff;
  --image-viewer-color: #111;
  --image-viewer-button-bg: transparent;
  --image-viewer-button-bg-hover: rgb(0 0 0 / 0.06);
}
```

## Labels from @nuxtjs/i18n

```ts
const { t } = useI18n()

viewer.open(items, 0, {
  labels: {
    dialog: t('viewer.dialog'),
    close: t('viewer.close'),
    prev: t('viewer.prev'),
    next: t('viewer.next'),
  },
})
```

## Fixed header that jumps when the page locks

Without `scrollbar-gutter: stable` on `<html>`, the page is padded by the scrollbar width while the viewer is open. Give your own fixed elements the same — or simply reserve the gutter:

```css
html {
  scrollbar-gutter: stable;
}
```
