## ImageViewerItem

One image passed to `open()`. Only `src` is required.

```ts
interface ImageViewerItem {
  /** Full-size image shown in the viewer. */
  src: string
  /** Smaller copy already loaded on the page — shown at once while `src` loads. */
  thumb?: string
  /** Natural size of `src`. Without it the image is measured before opening. */
  width?: number
  height?: number
  alt?: string
  /** Text shown under the image. */
  caption?: string
  /** Element on the page the image opens from and closes back into. */
  element?: HTMLElement
}
```

## ImageViewerOpenOptions

Overrides of the global options for one `open()` call.

```ts
type ImageViewerOpenOptions = Partial<{
  zIndex: number
  bgOpacity: number
  loop: boolean
  spacing: number
  maxZoom: number
  closeOnVerticalDrag: boolean
  closeOnBackdropClick: boolean
}> & {
  ui?: Partial<ImageViewerUi>
  labels?: Partial<ImageViewerLabels>
}
```

## ImageViewerSlide

An item with everything resolved — what `useImageViewer().items` holds.

```ts
interface ImageViewerSlide {
  src: string
  thumb: string
  width: number
  height: number
  alt: string
  caption?: string
  element?: HTMLElement
}
```
